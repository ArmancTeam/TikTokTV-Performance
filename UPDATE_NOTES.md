# V1.4 - GitHub update checks

- Checks the latest public GitHub Release after launch.
- Settings > Güncellemeleri kontrol et checks manually.
- If a newer release exists, opens its GitHub download page on user approval.
- Android installation remains user-controlled. This release does not silently install APKs.
- For updates to install over the existing app, keep the same package name and signing key.
- Publish V1.4 release after testing, with an APK asset.
